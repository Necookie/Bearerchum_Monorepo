## Problem Statement
Given an array of N positive integers, your task is to find the smallest positive integer that cannot be represented as the sum of any contiguous subarray.

For example, if the array is [1, 2, 5, 7], the contiguous subarray sums are:

- 1, 2, 5, 7 (single elements)
- 1+2=3
- 2+5=7
- 5+7=12
- 1+2+5=8
- 2+5+7=14
- 1+2+5+7=15

The set of achievable sums is {1, 2, 3, 5, 7, 8, 12, 14, 15}. The smallest positive integer missing from this set is 4.

## Input Format
- The first line contains an integer N, the size of the array, read after the prompt `Enter array size: `
- The second line contains N space-separated positive integers arr[i], read after the prompt `Enter the array elements: `

## Output Format
- Print a single integer representing the smallest positive integer that cannot be formed by a contiguous subarray sum, printed as `Smallest Missing Sum: X`

## Constraints
- 1 ≤ N ≤ 2000
- 1 ≤ arr[i] ≤ 100000
