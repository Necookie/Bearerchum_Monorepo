## Problem Statement
You are challenged to calculate the sum of the first N terms of a unique numerical sequence. Each term (Tᵢ) in this sequence is derived from the number i itself using a specific rule:

1. First, determine the sum of the digits of i. Let this sum be S.
2. Next, count the total number of digits present in i. Let this count be D.
3. Finally, the term T is calculated as S raised to the power of D (S^D).

Your task is to compute the total sum Sₙ = T₁ + T₂ + ... + Tₙ.

For example, if N = 3:

- For i = 1: Sum of digits S = 1, Number of digits D = 1. So, T₁ = 1^1 = 1.
- For i = 2: Sum of digits S = 2, Number of digits D = 1. So, T₂ = 2^1 = 2.
- For i = 3: Sum of digits S = 3, Number of digits D = 1. So, T₃ = 3^1 = 3.

The total sum S₃ = T₁ + T₂ + T₃ = 1 + 2 + 3 = 6.

## Input Format
- A single integer N, read after the prompt `Enter N: `

## Output Format
- A single integer representing the total sum Sₙ, printed as `Total sum: X`

## Constraints
- 1 ≤ N ≤ 100000
