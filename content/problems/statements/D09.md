## Problem Statement
Compress the text by writing each run of the same character as the character followed by the run length.

For example, `aaabccdddd` becomes `a3b1c2d4`.

## Input Format
- The text on one line, read after the prompt `Enter text: `

## Output Format
- `Encoded: …` followed by the encoded text

## Constraints
- 1 ≤ length ≤ 1000, no spaces
- Runs can be longer than 9 (`z12`).
- A single character becomes `x1`.
- Uppercase and lowercase are different characters.
