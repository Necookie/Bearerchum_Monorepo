## Problem Statement
Write a program to compute the alternating factorial sum, which is defined as: 1! - 2! + 3! - 4! + ... ± N!. The sum continues up to N!, and the sign of each term alternates. The first term (1!) is positive, the second (2!) is negative, the third (3!) is positive, and so on. In general, a term k! is added if k is odd and subtracted if k is even.

For example, if N = 4, the sum is 1! - 2! + 3! - 4! = 1 - 2 + 6 - 24 = -19.

## Input Format
- The input is a single positive integer N. You must prompt the user to enter this value with `Enter a positive integer N: `

## Output Format
- The program should print the final calculated sum. The output must be labeled: `The alternating factorial sum is: X`

## Constraints
- 1 ≤ N ≤ 20
