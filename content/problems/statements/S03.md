## Problem Statement
In this challenge, you will decrypt a string that has been encoded with a special rotational cipher. Unlike a standard Caesar cipher where the shift is constant, here the shift value changes for each character based on its position in the string.

The decryption rule is as follows: each alphabetic character is shifted backward in the alphabet by an amount equal to a given integer key plus the character's zero-based index. The alphabet wraps around, so shifting 'a' backward results in 'z'.

For example, if the key is 3 and the encoded string is 'kiqrv':

- The first character 'k' (at index 0) is shifted back by 3 + 0 = 3 positions, resulting in 'h'.
- The second character 'i' (at index 1) is shifted back by 3 + 1 = 4 positions, resulting in 'e'.
- The third character 'q' (at index 2) is shifted back by 3 + 2 = 5 positions, resulting in 'l'.
- And so on...

Your task is to write a program that takes an encoded string and an integer key, and outputs the original, decoded string. Non-alphabetic characters should remain unchanged.

## Input Format
- The first line of input will be the encoded string, read after the prompt `Enter the encoded string: `
- The second line of input will be an integer key, read after the prompt `Enter the key: `

## Output Format
- Print the decoded string, followed by a newline. The output should be prepended with `Decoded string: `.

## Constraints
- 1 ≤ length ≤ 1000
- 1 ≤ key ≤ 100
- Note: the third official sample uses key 0, so a key of 0 must work too.
