## Problem Statement
The noon temperature was recorded on each of **N** days in a row. A day is a **warmer day** if its temperature is **higher** than the day before it. The first day is never a warmer day. Print the number of warmer days.

For example, for the temperatures `28 30 29 29 31 33`, the days with 30, 31 and 33 are each higher than the day before, so there are **3** warmer days.

## Input Format
- **N**, read after the prompt `Enter N: `
- The **N** temperatures in day order on one line, read after the prompt `Enter the temperatures: `

## Output Format
- `Warmer days: W`, where **W** is the number of warmer days

## Constraints
- 1 ≤ N ≤ 50; each temperature is a whole number from −20 to 45.
- A day equal to the day before is not a warmer day.
- The count may be 0 (such as when **N** = 1).
