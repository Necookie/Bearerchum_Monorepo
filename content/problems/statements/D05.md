## Problem Statement
Given **N** numbers and **Q** questions “L R” (1-based, inclusive), print the sum of the numbers at positions L..R for each question.

For example, with numbers `3 1 4 1 5`, the query `2 5` asks for 1 + 4 + 1 + 5 = **11**.

## Input Format
- **N**, read after the prompt `Enter N: `
- The **N** integers on one line, read after the prompt `Enter numbers: `
- **Q**, read after the prompt `Enter Q: `
- The program then prints `Enter queries:` on its own line and reads **Q** lines, each with two integers `L R`.

## Output Format
- `Sum: S` on its own line for every query, in the order the queries were given

## Constraints
- 1 ≤ N, Q ≤ 10^5 → a loop per query is too slow; use prefix sums
- 1 ≤ L ≤ R ≤ N, and L may equal R
- Numbers are integers with absolute value at most 10^9 and may be negative.
