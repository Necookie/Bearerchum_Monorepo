## Problem Statement
A square subgrid is considered 180-degree rotationally symmetric if it remains the same after being rotated 180 degrees. This means that for a k x k subgrid starting at (r, c), the element at subgrid-local coordinates (i, j) must be equal to the element at (k-1-i, k-1-j) for all 0 ≤ i, j < k.

Given an N x N matrix, your task is to find the side length of the largest square subgrid that exhibits this 180-degree rotational symmetry.

For example, consider the 2x2 subgrid starting at (r, c):

```
A[r][c]     A[r][c+1]
A[r+1][c]   A[r+1][c+1]
```

For this subgrid to be symmetric, we need A[r][c] == A[r+1][c+1] and A[r][c+1] == A[r+1][c].

## Input Format
- The first line contains an integer N, the dimension of the matrix, read after the prompt `Enter size of matrix: `
- The program then prints `Enter matrix elements:` on its own line.
- The next N lines each contain N space-separated integers, representing the matrix elements A[i][j].

## Output Format
- Print a single integer: the side length of the largest 180-degree rotationally symmetric square subgrid, printed as `Largest symmetric subgrid size: X`

## Constraints
- 1 ≤ N ≤ 250
- 0 ≤ A[i][j] ≤ 1,000,000,000
