## Problem Statement
An Armstrong number equals the sum of its digits each raised to the number of digits (153 = 1³ + 5³ + 3³). Print all Armstrong numbers in [L, R].

## Input Format
- **L** and **R** on one line, separated by a space, after the prompt `Enter L and R: `

## Output Format
- `Armstrong numbers: …` with the numbers in increasing order, separated by spaces, or `Armstrong numbers: None` if there are none

## Constraints
- 1 ≤ L ≤ R ≤ 10^5
- Every 1-digit number is an Armstrong number.
- The range may contain none.
