## Problem Statement
Given **N** scores, print the second highest DISTINCT score. Repeated scores count only once. If it does not exist (every score is the same), print `None`.

For example, in `90 85 90 70 85` the distinct scores are 90, 85 and 70, so the second highest is **85**.

## Input Format
- **N**, read after the prompt `Enter N: `
- The **N** integer scores on one line, separated by spaces, read after the prompt `Enter scores: `

## Output Format
- `Second highest: X`, or `Second highest: None` if there is no second distinct score

## Constraints
- 1 ≤ N ≤ 1000
- Scores may repeat.
- Scores may be negative.
- All scores may be equal.
