## Problem Statement
The string "PAYPALISHIRING" is written in a zigzag pattern on a given number of rows (in this case row: 3) like this:

```
P   A   H   N
A P L S I I G
Y   I   R
```

And then read line by line: "PAHNAPLSIIGYIR".

Write a program that takes a string and a number of rows, and returns the converted string based on the zigzag pattern.

## Input Format
- The first line of input is a string s, read after the prompt `Enter string: `
- The second line of input is an integer numRows, representing the number of rows for the zigzag pattern, read after the prompt `Enter number of rows: `

## Output Format
- Print the converted string, which is formed by reading the zigzag pattern line by line, labeled `Converted string: `

## Constraints
- 1 ≤ s.length ≤ 1000, s contains uppercase and lowercase English letters
- 1 ≤ numRows ≤ 1000
